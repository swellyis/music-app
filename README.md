# Music Making App

A browser music studio in a single page: 16-step sequencer, scale-locked piano roll, multitrack timeline with clips and automation, mixer, synth drums and instruments, genre-based generators, MIDI keyboard input, WAV and MIDI export.

**Live:** https://swellyis.github.io/music-app/

## Install and offline use
It is a Progressive Web App. Open the link in Chrome or Edge and use **Install app**, or on iPhone/iPad choose Share → **Add to Home Screen**. After the first load it works fully offline.

## Files
- `index.html` — the whole app (HTML, CSS, JS and fonts inline)
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA files
- All paths are relative, so it runs from any sub-path or can be opened directly as a file.
